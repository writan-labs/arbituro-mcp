# Reporting a vulnerability

Email **support@arbituro.com** with what you found and how to reproduce it. Please do not open a
public issue for a vulnerability.

We will confirm we have it within three working days, and tell you what we did about it.

This covers the Arbituro MCP server at `app.arbituro.com/mcp`, the public API at
`app.arbituro.com/api/v1`, and the files in this repository. Please test only against a workspace
you own, and do not read or change anybody else's data.
